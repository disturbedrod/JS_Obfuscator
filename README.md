# JS Obfuscator

A Visual Studio Code extension for obfuscating JavaScript.

## Status

Project skeleton only. No functionality yet.

## Development

```bash
npm install
npm run compile
```

Press **F5** in VS Code to launch an Extension Development Host with the extension loaded.

## Packaging

```bash
npm run package
```

Produces a `.vsix` you can install via **Extensions → … → Install from VSIX**.
